# 角色关系图谱优化设计

## 1. 需求背景

当前角色关系图谱存在以下问题：
- 全局角色过多，导致每次都需要重新添加
- 缺乏与章节/场景的绑定能力
- 无法复用设定百科中已创建的角色

## 2. 设计目标

建立分层角色关系管理体系：
- **设定百科**：全局角色库，统一管理角色基础信息
- **全局关系图谱**：项目级默认关系，所有章节共用
- **章节关系图谱**：按需创建，可继承全局或其他章节图谱

## 3. 设计原则

- **默认全局**：只有全局关系图谱，无需为每个章节单独存储
- **按需创建**：只有在需要定制特定角色关系时才创建章节图谱
- **继承复用**：支持继承全局图谱或已有章节图谱，避免重复工作

## 4. 数据模型设计

### 4.1 角色（Character）
角色存储在设定百科中，作为全局资源。

```typescript
interface Character {
  id: string
  projectId: string
  name: string
  alias?: string[]
  summary?: string
  traits?: string[]        // 性格标签
  background?: string       // 背景故事
  avatarUrl?: string
  personalityPrompt?: string
  speechPattern?: string
  currentState?: string
}
```

### 4.2 全局角色关系（GlobalRelation）
项目级别的默认角色关系，所有章节默认共用。

```typescript
interface GlobalRelation {
  id: string
  projectId: string
  fromId: string           // 源角色ID
  toId: string             // 目标角色ID
  type: RelationType      // 关系类型：朋友/家庭/敌人/恋人/盟友/其他
  strength: number          // 关系强度 0-100
  notes?: string            // 备注
  createdAt: string
}
```

### 4.3 章节角色关系图谱（ChapterGraph）
按需创建的章节特有角色关系。

```typescript
interface ChapterGraph {
  id: string
  projectId: string
  chapterId: string         // 关联的文档ID
  parentGraphId?: string   // 继承的父图谱ID（全局图谱或其他章节图谱）
  createdAt: string
  updatedAt: string
}
```

### 4.4 章节特有关系（ChapterRelation）
章节图谱中该章节特有的关系（不包括继承的关系）。

```typescript
interface ChapterRelation {
  id: string
  graphId: string          // 关联的章节图谱ID
  fromId: string           // 源角色ID
  toId: string             // 目标角色ID
  type: RelationType
  strength: number
  notes?: string
  createdAt: string
}
```

## 6. 功能设计

### 6.1 全局图谱功能

| 功能 | 描述 | 操作方式 |
|------|------|----------|
| 查看/编辑全局角色 | 显示项目中所有全局角色 | 默认显示 |
| 添加角色 | 创建新的全局角色 | 点击「新建角色」|
| 引入角色 | 从设定百科选择已有角色 | 点击「引入角色」|
| 创建关系 | 连接两个角色创建关系 | Shift+拖拽 |
| 删除关系 | 移除两个角色间的关系 | 点击关系线删除 |
| 删除节点 | 从全局图谱移除角色（不影响百科）| 右键节点选择删除 |
| 清空全部 | 清除全局图谱所有关系 | 点击「清空全部」确认 |

### 6.2 章节图谱功能

| 功能 | 描述 | 操作方式 |
|------|------|----------|
| 查看本章图谱 | 显示该章节的角色关系 | 侧边栏点击已创建的章节 |
| 继承全局/其他图谱 | 复制被继承图谱的关系到本章 | 创建时选择继承 |
| 添加特有角色 | 添加该章节特有的角色 | 点击「添加角色」|
| 创建特有关系 | 创建本章特有的关系 | Shift+拖拽 |
| 删除特有关系 | 移除本章特有关系 | 点击关系线删除 |
| 删除特有角色 | 从本章移除该角色 | 右键节点选择删除 |
| 移除图谱 | 删除本章图谱，恢复使用全局 | 点击「移除图谱」确认 |

### 6.3 创建章节图谱流程

1. 侧边栏点击未创建的章节
2. 主区域显示创建引导
3. 选择「从零开始」或「继承全局/其他」
4. 如果选择继承，可选择具体继承哪些全局角色
5. 确认后创建章节图谱
6. 进入编辑模式

### 6.4 移除章节图谱流程

1. 在章节图谱中点击「移除图谱」
2. 弹出确认对话框
3. 确认后，该章节恢复使用全局图谱
4. 该章节特有的所有关系被删除

### 6.5 删除节点流程

1. 右键点击节点
2. 选择「从此图谱移除」
3. 节点从当前图谱删除
4. 如果是章节图谱，不影响全局和百科

## 7. 组件设计

### 7.1 CharacterGraphView（主视图）
- 管理全局/章节模式切换
- 处理数据加载和状态管理

### 7.2 GraphSidebar（侧边栏）
- Props: `graphs`（图谱列表）
- 显示全局图谱 + 已创建的章节图谱
- Events: `@select-graph`, `@create-graph`

### 7.3 GraphCanvas（图谱画布）
- D3 力导向图实现
- Props: `nodes`, `links`, `mode`, `inheritedLinks`
- 支持拖拽、缩放、关系创建
- 高亮显示继承的关系和特有关系

### 7.4 GraphCreationGuide（创建引导）
- Props: `chapterInfo`
- Events: `@create-empty`, `@inherit-global`, `@inherit-custom`

### 7.5 CharacterPicker（角色选择器）
- 弹窗形式
- Props: `characters`（可选列表）
- Events: `@select`, `@create`

### 7.6 RelationLine（关系线）
- Props: `link`, `isInherited`
- 继承的关系虚线显示，特有关系实线显示

## 8. API 设计

### 8.1 获取全局关系
```
GET /api/projects/:projectId/relations/global
Response: { relations: GlobalRelation[] }
```

### 8.2 获取章节图谱列表
```
GET /api/projects/:projectId/graphs
Response: { graphs: ChapterGraph[] }
```

### 8.3 获取章节图谱详情
```
GET /api/projects/:projectId/graphs/:chapterId
Response: {
  graph: ChapterGraph,
  relations: ChapterRelation[],        // 本章特有关系
  inheritedRelations: GlobalRelation[] // 继承自全局的关系
}
```

### 8.4 创建章节图谱
```
POST /api/projects/:projectId/graphs
Body: {
  chapterId: string,
  parentGraphId?: string,    // 可选，继承的图谱ID
  inheritCharacterIds?: string[] // 如果继承，可指定只继承这些角色
}
Response: { graph: ChapterGraph }
```

### 8.5 删除章节图谱
```
DELETE /api/projects/:projectId/graphs/:chapterId
```

### 8.6 创建全局关系
```
POST /api/projects/:projectId/relations/global
Body: { fromId, toId, type, strength, notes }
```

### 8.7 创建章节特有关系
```
POST /api/projects/:projectId/graphs/:chapterId/relations
Body: { fromId, toId, type, strength, notes }
```

### 8.8 删除关系
```
DELETE /api/projects/:projectId/relations/global/:relationId
DELETE /api/projects/:projectId/graphs/:chapterId/relations/:relationId
```

## 10. 验收标准

1. ✅ 默认只有全局关系图谱，简洁直观
2. ✅ 需要时才创建章节图谱，避免数据冗余
3. ✅ 支持继承全局或其他章节图谱
4. ✅ 可删除章节图谱，恢复使用全局
5. ✅ 侧边栏清晰区分已创建/未创建图谱的章节
6. ✅ 继承的关系和特有关系有明显区分
