# 前端归档区

`docs/archive/` 只存放已经失去当前执行价值、但仍需保留追溯信息的历史文档。

## 适合放入这里的内容

- 已完成专题的旧方案
- 被替代的阶段文档
- 旧版页面设计稿
- 仅用于回溯背景的历史说明

## 不应放入这里的内容

- 当前仍在维护的开发指南
- 仍作为 source-of-truth 的接口或架构文档
- 临时工作草稿

## 维护规则

1. 归档前先确认父仓库或当前目录已有新的有效入口。
2. 归档后应在原入口 README 或索引中说明新的 canonical 文档位置。
3. 归档不是删除。若文档仍被活跃引用，先补迁移说明再归档。
4. 前端 `docs/` 根层平铺文档的分类台账见 [2026-04-07-root-flat-doc-inventory.md](./2026-04-07-root-flat-doc-inventory.md)。
