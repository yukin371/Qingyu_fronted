## 1. 已知后端不支持的功能

### 1.1 导出模块 (export.ts)

| 功能         | 方法                    | 说明                       | 标记位置 |
| ------------ | ----------------------- | -------------------------- | -------- |
| 导出选中文本 | `exportSelection()`     | 后端不支持导出选中内容     | 第169行  |
| 全局导出历史 | `getAllExportHistory()` | 后端不支持全局导出历史查询 | 第205行  |
| 导出模板管理 | `getExportTemplates()`  | 后端不支持导出模板管理     | 第232行  |
| 保存导出模板 | `saveExportTemplate()`  | 后端不支持导出模板管理     | 第241行  |
| 批量导出     | `batchExport()`         | 后端不支持批量导出         | 第250行  |

### 1.2 发布模块 (publish.ts)

| 功能     | 方法                 | 说明                         | 标记位置  |
| -------- | -------------------- | ---------------------------- | --------- |
| 章节下架 | `unpublishChapter()` | 后端暂未提供章节下架接口     | 第240行   |
| 定时发布 | `scheduleChapter()`  | 后端暂未提供独立定时发布接口 | 第248行后 |
| 提交审核 | `submitReview()`     | 后端暂未提供提交审核接口     | 第248行后 |

### 1.3 管理员模块 (admin/wrapper.ts)

| 功能         | 方法           | 说明                            | 标记位置 |
| ------------ | -------------- | ------------------------------- | -------- |
| 完整用户更新 | `updateUser()` | 仅支持更新status或roles单个字段 | 第302行  |
